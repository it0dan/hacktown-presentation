# 📸 Diretório de Ativos dos Palestrantes (`assets/speakers/`)

Este diretório armazena as fotos e mídias visuais dos palestrantes do HackTown 2026.

## 📏 Especificações de Imagem

- **Formato Recomendado:** WebP, PNG ou JPG.
- **Dimensões:** Mínimo de `500x500px` (proporção 1:1, corte quadrado ou circular).
- **Resolução:** 72 a 150 DPI (otimizado para web).
- **Estilo Recomendado:** Fundo escuro ou transparente com iluminação contrastante para alinhamento com a identidade visual da capa.

## 🏷️ Padrão de Nomenclatura

Renomeie os arquivos utilizando o padrão *kebab-case*:
- `nome-sobrenome.jpg` (Exemplo: `danilo-amaral.png`, `ana-silva.webp`)

## 📌 Fotos Temporárias (Placeholders)

Caso uma foto oficial ainda não esteja disponível, utilize avatares em SVG com o mesmo aspecto quadrado.
